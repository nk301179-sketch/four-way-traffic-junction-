# four-way-traffic-junction-
The goal of this project is to design and build a scaled model of a four-way traffic junction controlled entirely by an Arduino Uno programmed in AVR Assembly language

I have built this system for Embedded Systems Engineering 2 person Assignment

Features :- 1. Day and Night mode determines by LDR 
            2. Day mode :- system switch between North,South red / East,West green to North,South green / East,West red
            3. Night mod:- Switch to a flashing yellow Night mode based on ambient light sensing.
            4. A pedestrian crossing has built in the south side and can only interrupt day mode cycle  

Components :- Arduino Uno, LDR sensor and LEDs
Language :- AVR Assembly
